# FitTracker-Final

A React + Vite fitness tracker app prepared for Vercel deployment.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Deploy

Push to a Git repository and connect it to Vercel. The default build command is `npm run build` and the output directory is `dist`.
